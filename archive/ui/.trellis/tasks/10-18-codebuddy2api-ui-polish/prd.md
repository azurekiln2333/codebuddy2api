# CodeBuddy2Api UI polish round 2

用户需求（2026-10-18），由 4 个 pi 并行实施，根协调者（Claude，pane w1F:p1）验收并统一提交。

## 分工与验收标准

### pA：外壳 / 品牌 / 侧栏
- 所有用户可见的 AzureKiln 改为 CodeBuddy2Api（title、顶栏、登录页、i18n 中英）；内部类名和标识不改。
- 删除侧栏“管理工作区 / 管理员”卡片、侧栏底部“管理员会话”、主体底部“AzureKiln · 管理控制台”页脚。
- 侧栏展开/收起有平滑动画，参考 new-api/web：宽度过渡、文字淡出、图标位置不跳；遵守 prefers-reduced-motion。

### p7：圆角 / 卡片边线
- 圆角以 new-api/web 的 0.5rem 档为基准，在 theme.scss 统一设置 token，各模块引用 token，不再写死大圆角。
- 所有页面卡片外部上下多余的横线（border-top/bottom、::after 分隔、hr）全部去除；卡片自身边框、表格行分隔线、表头线保留。
- 浏览器截图确认。

### p8：凭证 / 存储
- “全部账号”卡片只显示一条正确的额度条；若原本是两个不同指标，改为单一、清楚标注的展示。
- 存储管理不再显示 not found：前端问题直接修；后端缺接口则不改后端，页面显示友好的不可用提示。

### p9：令牌管理
- 调研后端是否支持多个 API key 的增删改查（后端只读）。
- 支持：新增令牌管理页（列表、创建、一次性显示并复制、启停、删除二次确认），路由和侧栏入口最小化接入。
- 不支持：不做页面，汇报现状和建议接口。

## 共同约束
- 只改自己负责的范围；编辑前先重读文件，只做小范围替换；禁止整文件重写、git checkout/restore/stash/reset/clean、全仓库 format --write。
- 不 commit、不 push、不部署；API/SSO/CSRF/权限语义不变；new-api 只作参考，不复制源码。
- 完成后跑 check 和单元测试，汇报后写 DONE。

## 根协调者验收
