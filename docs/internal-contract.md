# Implementation contracts

TS ESM `.js` imports, node:http, jose. Ownership is in design.md. Workers must accommodate concurrent edits, never revert others, never commit or write reference repos. Child loads implement/check jsonl then prd/design/implement if native injection unavailable.

`GatewayConfig` from src/config.ts: publicOrigin, oidcIssuer, oidcClientId, oidcClientSecret, upstreamOrigin, upstreamApiKey, host, uiStaticDir (strings); port, sessionTtlMs, sessionIdleMs, transactionTtlMs, maxSessions, oauthTimeoutMs, upstreamTimeoutMs, streamTimeoutMs, maxBodyBytes (numbers); oidcRefresh, allowInsecureLocalhost (booleans). Origins no trailing slash. OAuth URLs HTTPS except explicit loopback dev. Cookie Secure except HTTP loopback dev.

src/http.ts exports HttpError(status:number,code:string), json(res,status,value), readJson(req,maxBytes):Promise<Record<string,unknown>>, requireSameOrigin(req,config), requireCsrf(req,session,config). Origin exact match, reject cross-site Fetch Metadata. CSRF timing-safe equals session.csrfToken. Mutation Origin cannot be missing.

Auth exports GatewaySession from src/sessions.ts: id,csrfToken,sub,accessToken (strings); user:{sub:string,username?:string,name?:string,role:"admin"}; refreshToken?:string; accessTokenExpiresAt,expiresAt,lastSeenAt (numbers); upstream?:{cookie:string,csrfToken:string}; upstreamLogin?:Promise<void>; refreshPromise?:Promise<void>. Additional private fields allowed. AuthService(config,cleanup?:(session)=>Promise<void>) has handle(req,res,url):Promise<boolean> for /sso/*, requireAdmin(req,res):Promise<GatewaySession> (live check each invocation), logout(req,res):Promise<void>, close():void. GET /sso/session 401 includes unauthenticated shape; safe errors only.

GatewayProxy(config) exports admin(req,res,url,session):Promise<void>, inference(req,res,url):Promise<void>, logout(session):Promise<void>, close():void. Caller/server authorizes BEFORE admin. Per-session synchronized bridge; strip browser auth/cookie/CSRF/identity, inject real cookie/CSRF/canonical backend Origin. Inference keeps caller auth, drops all cookies. Suppress upstream Set-Cookie/CORS. Main synthesizes GET /admin/session, denies POST, maps DELETE to auth.logout.

serveStatic(req,res,url,config):Promise<boolean> exported src/static.ts for dashboard routes only. src/server.ts exports createGateway(config):http.Server, validates RAW request target before URL parsing/classification, error redaction, explicit route allowlist, /healthz. src/main.ts entrypoint. Tests real HTTP ephemeral ports with explicit local dev opt-in.

Raw path contract: `validateRequestTarget(target, method = "GET")` runs before URL parsing. Percent encoding in pathnames is rejected except in the model ID for `PUT`/`DELETE /admin/models/{id:path}` and `POST /admin/models/{id:path}/preview`; the prefix and preview suffix must be literal. Decode that ID exactly once, require 1–160 ASCII characters from `[A-Za-z0-9_.:/@-]`, and reject empty, `.` or `..` slash segments. This excludes residual percent escapes/double encoding, backslashes, whitespace, query/fragment characters and non-ASCII IDs. Preserve the accepted encoded path when forwarding so ASGI decodes the same ID once; IDs such as `org/model`, `vendor:model` and `@org/model` remain supported. Elsewhere ASGI-encoded aliases such as `/admin/%73ession` remain rejected. Dot segments, duplicate separators, URL normalization changes and `/admin/session/` aliases are rejected before classification/proxy. Query encoding is allowed; static UI artifacts must use literal ASCII paths.
