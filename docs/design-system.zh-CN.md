# CodeBuddy2Api 控制台设计规范

[English](design-system.md)

本规范描述 `web/` 的视觉与交互契约。2026-11-07 根据本地 `cnb2api-panel`
实际截图重新核对。实现位于 `theme.scss`、`ui.module.scss`、
`dashboard.module.scss` 和 `management.module.scss`。

## 设计来源与字体

参考项目的尺寸、间距、颜色和布局在 React + SCSS Modules 中独立实现。
未移植 Vue 源码或参考项目的认证协议。保留 CodeBuddy2Api 品牌与立方体标记。
原有 MIT 来源和许可见 `web/LICENSE.upstream` 及 `web/THIRD_PARTY_NOTICES.md`。

界面使用 DM Sans Variable，代码使用 JetBrains Mono Variable。
两款字体通过固定版本的 Fontsource 包本地打包，不请求外部字体服务。
中文使用 Segoe UI、微软雅黑、苹方等系统回退字体。
构建产物 `THIRD_PARTY_LICENSES.txt` 包含字体 OFL 全文。

## 色彩与控件

组件使用 `theme.scss` 中的语义变量。明暗主题不改变布局。

| 用途 | 浅色 | 深色 |
| --- | --- | --- |
| 主色 | `#3169df` | `#78a2ff` |
| 页面 / 侧栏 | `#f8f9fb` / `#f2f4f7` | `#14181f` |
| 内容表面 | `#fff` | `#1b2029` |
| 正文 | `#232b3a` | `#e1e7f0` |
| 次级 / 弱文字 | `#596477` / `#7d8798` | `#abb5c5` / `#8590a1` |
| 边框 | `#e9edf2` | `#2a313e` |
| 导航选中背景 | `#cfddf2` | `#b8cceb` |
| 导航选中描边 | `#9fb5d6` | `#829dc6` |

选中导航两种主题均为黑字，左侧 3px 内嵌标记为 `#1e40af`。
品牌方块始终使用 `#3169df`。状态同时使用文字与成对状态色。

圆角阶梯为 4 / 8 / 12 / 16 / 28 / 999px。
控件圆角 8px，卡片 12px，桌面内容外壳 16px。
普通按钮最低 36px、14px 字体、8px 13px 内距。
标题区按钮采用 32px 紧凑尺寸。手机其他主要操作最低 40px。
表头最低 36px、数据行最低 48px，多行内容自然增高。

页面标题为 24px/650，配 11px 英文眉题、蓝短线及 14px 说明。
业务卡片使用轻阴影，不使用悬浮抬升。菜单和弹窗使用浮层阴影。

## 加载与登录

会话检查时显示居中的品牌方块、20px loader 与“正在连接控制台”。
使用 `role="status"`。减少动态效果偏好会关闭动画。

桌面登录采用 `1.08fr 1fr` 双栏。左栏内距 42px 50px 28px，
包含浅色点阵、品牌、两行 38px 标题与网关连接图。
右侧居中卡片最多 320px 宽，包含 48px 盾牌、眉题、25px 标题、提示和 SSO 链接。
SSO 链接为细边框按钮，桌面高 42px，手机至少 44px。
参考站点实际按钮为 39px，本项目保留较大的点击区域。

1050px 以下缩小叙事内距和标题。600px 以下改为单栏：
品牌区内距 26px 25px、品牌 23px。隐藏 CONSOLE 辅助标签以容纳较长品牌。
隐藏叙事和连接图，表单保持竖向居中，最多 330px 宽。
主题按钮保持完整点击区域，320px 下也不与品牌重叠。

唯一登录入口为 `/sso/login?return_to=/dashboard/`。
不显示管理密码或 API key 输入框。错误及权限不足仍提供提示和重新检查操作。
外观按钮使用明暗图标，继续打开主题、系统跟随和语言设置抽屉。

## 外壳与滚动

外壳固定为 100dvh。顶栏高 52px，全宽，桌面内距 0 16px。
包含折叠按钮、品牌、面包屑、外观和账号菜单。
账号菜单保留身份与退出操作，可由 Escape 或外部点击关闭。

桌面侧栏宽 180px，折叠后 64px。两组导航项高至少 36px。
文字和组标题淡出但保持挂载。折叠时图标位置不变，顶栏品牌仍显示。

内容面板位于 x=180、y=60，顶部、右侧和底部均留 8px，折叠后 x=64。
面板采用 1px 边框、16px 圆角和内部滚动。
必须设置 `position: relative`，避免图表绝对定位的读屏提示撑高外层文档。
正文最多 1600px 宽，内距 20px 22px 18px，1250px 以下横向收至 18px。
切页后面板 scrollTop 归零。页脚随内容滚动，两个许可链接必须可达。

800px 以下隐藏桌面侧栏。内容面板四边 8px，圆角 12px。
手机导航使用原生模态 `dialog`，从 x=0、y=52 打开，宽 208px。
遮罩从顶栏下方开始。保留关闭按钮、滚动锁、焦点隔离和关闭后的焦点恢复。
选择路由或按 Escape 关闭。手机正文横向内距 16px，440px 以下为 14px。

## 九个业务页

概览、凭证、模型、媒体、密钥、日志、存储、设置和更新共享标题及控件。
媒体和更新卡片同样使用 12px 圆角与轻阴影。

首页依次展示 Token/Credit 双摘要、四项指标、Token 明细、官方余额、
趋势和凭证健康双列、模型排行及产品分布。
摘要顶边分别为蓝色与琥珀色，主数值 30px。
指标数值 24px，手机 22px，间距 10px，内距 12px 14px 11px。
仅使用本项目实际 API 字段，不引入参考站点的 CNB 额度或工作区语义。
缺失值仍显示未知。

表格横向滚动限制在自身容器，长标识不撑宽页面。
密钥名称列至少 120px 宽，在表格容器内横向滚动。
KPI 图标尺寸只作用于 SVG 容器，不能限制数字或保留时长说明。
设置保留可修改、外部锁定、系统只读三种状态，切换分类不丢未保存的修改。
保留加载、重试、权限撤销、精确确认和 CSRF 契约。
